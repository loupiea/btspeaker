# 风险清单与应对策略

更新日期：2026-07-09

## 1. 芯片资料风险

### ESP32 裸芯片 RF Layout 难度高

可能表现：

- 蓝牙距离差。
- 蓝牙音频断续。
- 天线匹配不佳。
- 量产一致性差。

应对：

- 第一版严格参考 ESP32 官方硬件设计指南。
- 优先使用陶瓷天线或成熟参考天线。
- RF 匹配网络预留调试位。
- 用户指定首版 2 层板，因此必须放大板子、保持底层 GND 连续，并严格参考 ESP32 官方 RF 布局。

### 电脑有线 USB Audio 被取消

可能表现：

- 首版不能通过 USB 数据线作为电脑声卡使用。
- 用户容易误以为 USB-C 或 USB-A 可以接电脑传音频。

应对：

- 文档和外壳标识明确：USB-C 只供电/充电，USB-A 只接 U 盘。
- 电脑近场使用蓝牙连接。
- 有线电脑输入使用 AUX + Codec/ADC 作为保底，USB Audio 放到后续版本评估。

### USB-A 口被误接电脑

可能表现：

- USB-A Host 口被用户用 A-to-A 线接到电脑。
- 电脑和音箱都可能向 VBUS 供电，产生倒灌风险。

应对：

- 首版明确 USB-A 只接 U 盘，不支持接电脑。
- U 盘 5V 单独加电源开关、限流和过流检测。
- USB-A VBUS 增加防倒灌和过流保护。

### U 盘兼容性不足

可能表现：

- 某些 U 盘不识别。
- 大容量或特殊分区格式不识别。
- 播放中途读文件卡顿。

应对：

- 首版限定 FAT32。
- 首版限定常见小容量 U 盘。
- 使用 CH376S 裸芯片降低固件复杂度，优先 SPI 接 ESP32；CH376 只作为同系列备选，不在首版混用。
- 测试 3 个以上不同品牌 U 盘。

### TF/SD 卡兼容性不足

可能表现：

- 插卡检测不稳定。
- 卡读写速度不足。
- 文件系统损坏后固件卡死。

应对：

- 首版只读文件，不做写入。
- 使用 FAT32。
- 插拔状态机要能处理异常拔卡。
- 卡座加 ESD 防护和合适上拉。

## 2. PCB 设计风险

### 蓝牙距离差

可能原因：

- 天线净空不足。
- 射频匹配错误。
- 天线被金属外壳或线材遮挡。
- 开关电源干扰射频。

应对：

- 第一版严格照参考设计布天线。
- 天线区域不铺铜、不放金属件。
- 蓝牙远离 Buck 电感和功放输出。
- 外壳阶段重新测试距离。

### USB 不稳定

可能原因：

- 差分线阻抗和长度不合适。
- ESD 器件电容过大。
- USB 座封装或引脚定义错误。

应对：

- USB D+/D- 短、等长、少过孔。
- 使用低电容 USB ESD 器件。
- 打样前人工核对 USB 座封装。

### 底噪、电流声、串音

可能原因：

- 模拟音频线靠近 Buck 或 D 类功放输出。
- 模拟地、数字地、功率地规划不合理。
- 电源纹波进入 MAX98357A 或 ES8388。
- 输入选择和音量控制阻抗不合适。

应对：

- 模拟音频区域独立布局。
- 模拟电源使用低噪声 LDO。
- 小信号线短且远离高 dv/dt 节点。
- 第一版 PCB 预留可改阻容的位置。

## 3. 电源风险

### 上电烧芯片

可能原因：

- 电源轨短路。
- Buck 反馈电阻错误。
- LDO 输入输出接反。
- 芯片焊接方向错误。

应对：

- 分阶段焊接和限流上电。
- 先验证电源再焊贵重芯片。
- 每个电源轨预留测试点。
- 首次上电记录电压和电流。

### USB-C 5V 供电能力不足

可能原因：

- USB-C 5V 适配器电流不足。
- 线材压降大，5V 系统电源跌落。
- 边充边播时 IP5306 充电、电池升压和 MAX98357A 瞬态电流叠加。
- 适配器功率不足。

应对：

- 首版明确 USB-C 5V 输入，适配器建议至少 2A。
- PCB 上保留 5V 输入、IP5306 5V 输出、电池电压和 3.3V 测试点。
- 固件检测 5V 跌落或电池低压时限制音量或静音功放。
- IP5306 路线适合 5V + 1S 电池的小型音箱，但必须实测边充边播、大音量、U 盘读取同时发生时的温升和 5V 纹波。

### 功放导致电源跌落

可能原因：

- USB-C 5V 适配器、电池或 IP5306 升压 5V 输出电流不足。
- 功放大电流回路太长。
- 电源滤波电容不足。

应对：

- USB-C 5V 适配器、电池和 IP5306 升压 5V 都要留足功率余量。
- 功放电源线加宽，回路紧凑。
- 功放附近放足够储能电容。
- MAX98357A 使用 5V 功放电源，不能直接接 1S 电池；ESP32 I2S/PCM 直接接 MAX98357A 输入。
- 大音量测试时观察 USB-C 5V 和 IP5306 电池升压 5V 下的纹波、跌落和自动限音量策略。

### 锂电池安全风险

可能原因：

- 充电管理参数错误。
- 电池自带保护板参数不清楚或保护能力不足。
- 边充边播时系统负载和充电电流互相影响，导致充不满、重启或电池异常发热。
- 过放导致电池损坏。
- 电池短路或连接器反接。
- 电池仓固定不可靠，移动时挤压或磨线。

应对：

- 使用自带保护板的 1S 锂电池，并核对保护板参数。
- 充电终止电压按 1S 锂电池设置为 4.2V。
- 电池固定为 1S 3.7V 2500mAh 自带保护板锂电池；PCB 和线束上明确标正负极。
- IP5306 需要按 datasheet 的充放电同步/升压应用验证边充边播；系统 5V 负载接 IP5306 输出侧，不能把系统负载直接并到电池充电端。若实测出现边充边播重启、充电异常或温升过高，第二版再增加外部负载共享、理想二极管或更强电源管理方案。
- 首版充电电流建议 0.5A-1A，先以安全和温升可控为目标。
- 电池连接器尽量选防反接结构。
- 固件检测电池电压，低电压时静音并关机。
- 电池仓做绝缘、固定和线材应力释放。
- 不在无人看管时进行首次充电和高功率放电测试。

## 4. 音频安全风险

### 开关机爆音

可能原因：

- 功放比前级先启动。
- MAX98357A 或 ES8388 输出未稳定。

应对：

- MCU 控制功放 MUTE，上电延时打开。
- 关机时优先静音功放。
- 第二版根据测试结果增加 RC 延时或专用静音电路。

## 5. 固件风险

### 输入切换混乱

可能表现：

- 蓝牙、TF/SD、U 盘、AUX 状态不清楚。
- 切换时爆音。
- LED 指示和实际输入不一致。
- 本地播放时播放/暂停或音源切换状态混乱。

应对：

- 固件使用明确状态机。
- 切换输入前先静音，切换后延时解除静音。
- 每个状态都有测试用例。
- 存储设备拔出时必须先停止解码和静音输出。

### 立体声声道和相位错误

可能表现：

- 左右声道接反。
- 一只喇叭反相导致低频变弱。

应对：

- 原理图、PCB 丝印、线材都标 L/R。
- 测试时使用左右声道测试音。
- 喇叭正负极和功放输出保持一致。

### 音量控制体验差

可能表现：

- 音量跳变。
- 最小音量仍过大。
- 旋转编码器抖动或漏步。
- OLED 状态显示和实际音源/音量不同步。

应对：

- 编码器做软件消抖和加速曲线。
- 数字音量使用合适步进曲线。
- OLED 显示由统一状态机刷新，不在多个任务里各写各的。
- 保留前级增益调整电阻。

## 6. 结构风险

### 外壳共振

可能原因：

- 板材太薄。
- 喇叭固定不牢。
- 腔体漏气。
- 内部线材碰撞。

应对：

- 喇叭安装加密封垫。
- 外壳加加强筋。
- 线材固定避开振膜。
- 通过扫频找共振点。

### 接口受力损坏 PCB

可能原因：

- USB、电源接口只靠焊点承力。
- 面板孔位偏差。

应对：

- 选择带定位柱或固定脚的连接器。
- 接口附近加机械固定。
- 面板和 PCB 固定孔一起设计。

## 7. 项目进度风险

### 全自研复杂度过高

表现：

- 蓝牙、TF/SD、U 盘、AUX、功放、电源、结构同时出问题。
- 长时间听不到声音。

应对：

- 按电源、MCU、USB、蓝牙、音频、功放分块调试。
- 每个阶段只解决一个主问题。
- 第一版 PCB 以可测、可飞线、可返修为优先。

### 采购不确定

表现：

- 芯片缺货。
- 封装太难焊。
- 资料与实物不一致。

应对：

- 关键 IC 至少准备两个候选。
- 第一版避免过小封装，优先选择可手工返修封装。
- 每个芯片记录型号、封装、供应来源和资料版本。

## 8. 质量风险

### 样机能响但无法复现

可能原因：

- 飞线修改没有记录。
- BOM 版本没有记录。
- PCB 改动没有版本号。

应对：

- 每块 PCB 编号。
- 每次飞线和割线都拍照记录。
- BOM、原理图、PCB、固件使用同一版本号。
- 测试记录写清楚问题和处理方式。
