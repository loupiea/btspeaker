# BOM 与采购计划

更新日期：2026-07-09

## 1. 采购原则

本项目采购芯片和基础元器件，不采购现成蓝牙音频模块、USB 声卡模块、功放模块、电源模块来拼装整机。

允许采购：

- IC 芯片。
- 通用 MCU/无线模组，例如 ESP32-WROOM-32E；它不是成品蓝牙音频接收模块，仍需要自行设计音频、电源、接口、PCB 和固件。
- 晶振、天线、连接器、阻容感、保护器件。
- 喇叭、USB 座、DC 座、开关、旋钮。
- PCB 打样和 SMT 焊接服务。
- 外壳材料、螺丝、铜柱、线材。

不作为最终方案采购：

- 成品蓝牙音频接收模块。
- 成品 USB 声卡模块。
- 成品 D 类功放模块。
- 成品 DC-DC 降压模块。

调试阶段如临时用开发板或评估板，只能用于理解芯片和对照验证，不能作为整机方案的一部分。

## 4. 采购批次

第一批：芯片预研和基础物料

- ESP32-WROOM-32E 模块采购和官方资料归档；ESP32-D0WD-V3 裸芯片、外部 Flash、晶振和 RF 物料仅作为 V2 预研，不进入首版 BOM。
- TF/SD 卡座和 CH376S U 盘 Host 芯片资料归档。
- AUX Codec/ADC 固定 ES8388；采购前确认封装、供电、I2S/I2C 引脚和 line-in 接法。
- MAX98357A 数字功放 IC 2-4 颗。
- SY8088IAAC、IP5306、LDO/滤波电源物料。
- 1S 3.7V 2500mAh 自带保护板锂电池、IP5306、IP5306 外围电感/电容、USB-A 负载开关和必要的防倒灌/保护器件。
- 常用阻容感、RH2.0 2P 电池连接器、USB-A/USB-C、保护器件。

第二批：PCB 打样

- 第一版 PCB 5 片。
- 钢网。
- 关键 IC 多买 2-3 颗备用。
- 返修耗材：焊锡、助焊剂、吸锡带、热风嘴。

第三批：结构和声学

- 喇叭。
- 先裸板测试；外壳材料放到核心链路跑通后再采购。
- 螺丝、铜柱、密封棉、吸音棉。
- 旋钮、面板、脚垫。

第四批：第二版修正

- 根据第一版问题调整芯片和器件。
- 打样第二版 PCB。
- 准备 5-20 台小批量物料。

## 5. 工具和设备

强烈建议准备：

- 万用表。
- 可调直流电源，最好带限流。
- 示波器。
- USB 逻辑分析仪。
- 热风枪和恒温烙铁。
- 音频测试文件。
- 假负载电阻，代替喇叭做功放初测。
- USB 电流表。

有条件再准备：

- 音频分析仪。
- 频谱仪或近场探头。
- 热像仪。
- 蓝牙协议测试工具。
