# 蓝牙音箱长期路线图

更新日期：2026-07-09

## 阶段 0：需求冻结与芯片预研

建议周期：2-3 周

目标：

- 明确整机规格。
- 确认全部自研，不走现成模块拼装路线。
- 选定关键芯片候选。
- 收集 datasheet、参考设计、应用笔记和封装资料。

关键决策：

- 蓝牙：使用 ESP32-D0WD-V3 裸芯片 + 外部 16MB SPI Flash + 40MHz 晶振，不使用蓝牙音频模块；基于 ESP-IDF A2DP sink 和 I2S 输出自研固件。
- 电脑输入：首版电脑近场听音走蓝牙；有线电脑输入通过 AUX + Codec/ADC 接入，不做 USB Audio 声卡口。
- 本地播放：TF/SD 卡和 U 盘两个都做；主控直接读 TF/SD 卡，U 盘通过 CH376S 裸芯片读取，和 ESP32 走 SPI。
- 文件格式：首版只支持 MP3/WAV，暂不承诺 FLAC、APE、AAC。
- 音频链路：旋转编码器 + ESP32 数字音量控制。
- 功放：固定为 MAX98357A x2，左右声道各 1 颗 I2S 数字功放；USB-C 5V 和 1S 锂电升压 5V 供电，首版按近场桌面小功率定位。
- 电池：改为 1S 3.7V 2500mAh 锂电池，使用 IP5306 实现 1S 充电和升压 5V；边充边播必须按 datasheet 和实测结果验证。
- PSRAM：首版不加，避免占用引脚、增加布线和调试复杂度。

交付物：

- 功能需求表。
- 芯片候选表。
- 系统框图。
- 初版 BOM。
- 风险清单。

## 阶段 1：核心方案定型

建议周期：2 周

目标：

- 选定第一版芯片组合。
- 明确电源树、音频链路、控制逻辑和接口定义。
- 为原理图设计做准备。

推荐首版组合：

- 蓝牙：ESP32-D0WD-V3 裸芯片，外接 16MB SPI Flash 和 40MHz 晶振。
- USB：USB-C 只做 5V 供电/充电；USB-A 只做 U 盘 Host 口。
- 存储：TF/SD 卡座接 ESP32 SPI；U 盘使用 CH376S 裸芯片接 ESP32 SPI。
- 解码：主控软件解码 MP3/WAV，或后续增加专用音频解码 IC。
- 音频：ESP32 输出数字 PCM/I2S，直接进入 MAX98357A x2；不使用 ESP32 内部 DAC 作为正式音频输出。
- 功放：MAX98357A x2，左右声道各 1 颗。
- 存储器：外接 16MB SPI Flash；首版不外接 PSRAM。
- 控制：ESP32 负责输入切换、OLED 显示、静音、按键和旋转编码器检测。
- 电源：USB-C 5V 输入 + IP5306 + 1S 3.7V 2500mAh 锂电池；电池接口使用 RH2.0 2P；通过 IP5306 实现 1S 充电和升压 5V，再由 SY8088IAAC 输出 3.3V。边充边播作为首版重点测试项。

验收标准：

- 每个芯片都有可获得资料和可采购封装。
- ESP32 芯片 datasheet、硬件设计指南、ESP-IDF A2DP 示例、I2S 示例和烧录工具链需下载并归档。
- 每个接口都有明确电平、时钟、供电和信号方向。
- 音频链路从输入到输出可以画成闭环。

## 阶段 2：原理图设计

建议周期：3-4 周

目标：

- 完成第一版自研原理图。
- 做 ERC 检查和人工设计审查。
- 输出可打样 PCB 的设计输入。

主要工作：

- ESP32-D0WD-V3 最小系统：3.3V 供电、外部 40MHz 晶振、外部 16MB SPI Flash、复位/下载电路、UART 下载口、天线/RF 匹配、I2S 音频输出。
- USB-A U 盘输入：ESD、防护、USB 差分线、USB Host/文件管理芯片外围。
- TF/SD 卡：卡座、ESD、上拉、电源去耦；首版 TF/SD CD 只预留测试点，不接 ESP32。
- U 盘：USB-A 母座、5V 负载开关、ESD、CH376S 裸芯片外围，和 ESP32 走 SPI。
- 音频链路：I2S、MAX98357A 左右声道配置、数字音量、静音控制。
- 功放：MAX98357A x2、5V 功放电源、喇叭保护和 EMI 控制。
- 电源：USB-C 5V 输入、IP5306、1S 锂电池保护、升压 5V、SY8088IAAC 3.3V、模拟/数字分区供电。
- MCU：播放暂停、音源切换、旋转编码器音量、OLED、输入检测、静音控制；IP5306 开关机由独立电源按键负责。

验收标准：

- 原理图无明显悬空电源或错误网络名。
- 关键芯片外围与 datasheet 推荐一致。
- 电源时序和电压等级清楚。
- 电池充电、放电、保护、电量检测和边充边播逻辑清楚。
- 所有连接器引脚定义清楚。

## 阶段 3：PCB Layout 与打样

建议周期：3-5 周

目标：

- 完成第一版 PCB。
- 控制射频、USB、音频小信号、功放大电流和电源回路布局。

主要工作：

- 蓝牙天线区域留净空。
- USB 差分线等长和阻抗控制。
- 模拟音频走线短、远离开关电源和功放输出。
- 功放电源和喇叭输出走线加宽。
- 数字地、模拟地、功率地合理分区和单点汇聚。
- 电源 IC 附近按 datasheet 放置电感、电容、二极管或同步器件。
- 预留测试点：电源、I2S、复位、UART 下载口、左右声道音频、功放使能。

验收标准：

- DRC 通过。
- 关键器件封装确认。
- 接口位置适合外壳。
- 测试点足够调试。
- 输出 Gerber、BOM、坐标文件。

## 阶段 4：焊接与分块调试

建议周期：4-6 周

目标：

- 按电源、控制、USB、蓝牙、音频、功放顺序逐步上电。
- 不一次性全板通电冒险。

调试顺序：

1. 空板检查和短路检查。
2. 只焊电源输入和稳压，确认电压正确。
3. 焊 MCU，确认下载和 GPIO。
4. 焊 OLED 和按键/编码器，确认 I2C 与 GPIO。
5. 焊蓝牙/RF 相关外围，确认启动、配对或串口日志。
6. 焊 TF/SD 和 CH376S/U 盘读取部分，确认能枚举文件。
7. 焊 MAX98357A x2，先接假负载确认 I2S 左右声道输出。
8. 接喇叭，低音量开始测试整机播放。

验收标准：

- 每个电源轨电压和纹波在可接受范围。
- USB-C 5V 输入正常；USB-A 只能识别 U 盘，不作为电脑 USB 设备。
- 蓝牙可被手机发现和连接。
- TF/SD 卡和 U 盘可读取测试文件。
- 音频链路可播放测试音。
- 功放无异常发热。

## 阶段 5：结构和声学样机

建议周期：3-5 周

目标：

- 先裸板测试，核心链路跑通后再把自研 PCB 装入外壳。
- 验证喇叭腔体、接口位置、旋钮手感、散热和抗干扰。

主要工作：

- 设计外壳、喇叭安装、PCB 固定孔、接口面板。
- 测试密闭箱和倒相箱差异。
- 处理外壳共振、漏气、线材固定。
- 优化天线位置，避免被金属和电源线遮挡。

验收标准：

- 外壳无明显共振异响。
- 蓝牙距离不因外壳明显变差。
- 接口操作方便。
- 连续播放 2 小时无热问题。

## 阶段 6：第二版 PCB 修正

建议周期：3-5 周

目标：

- 根据第一版调试问题修正原理图和 PCB。
- 提升稳定性、音质和可装配性。

常见修正：

- 改电源滤波。
- 改地线汇聚。
- 改天线净空。
- 增加静音控制。
- 调整音频增益。
- 增加测试点。
- 调整接口和固定孔。

验收标准：

- 第一版主要问题关闭。
- 第二版样机可重复焊接和测试。
- 文档和 BOM 同步更新。

## 阶段 7：小批量试制

建议周期：4-8 周

目标：

- 做 5-20 台自研 PCB 样机。
- 验证一致性、装配效率、故障率和成本。

交付物：

- 固化 BOM。
- 装配流程。
- 烧录流程。
- 测试流程。
- 故障处理表。
- 版本变更记录。
