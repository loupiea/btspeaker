# 蓝牙音箱技术方案

更新日期：2026-07-09

## 1. 自研边界

本方案不使用现成蓝牙音频模块、USB 声卡模块、功放模块或电源模块。允许使用芯片和基础元器件，并基于 datasheet、参考设计和应用笔记自行设计原理图、PCB 和固件。

自研范围包括：

- 蓝牙音频电路。
- TF/SD 卡本地播放电路。
- U 盘本地播放电路。
- AUX 有线音频输入电路。
- 音频选择和音量控制电路。
- 功放电路。
- 电源保护、锂电池充电/保护、降压、滤波电路。
- MCU 控制和固件。
- PCB Layout、外壳结构、测试流程。

## 2. 系统模块划分

整机拆成 8 个自研单元：

- 蓝牙音频/主控单元：ESP32-WROOM-32E 模块、3.3V 供电、EN/BOOT 下载电路、UART 下载口、模块天线净空、I2S 音频输出。
- TF/SD 单元：卡座、ESD、SPI 总线、电源去耦；首版不把插卡检测接入 ESP32，只预留测试点。
- U 盘单元：USB-A 母座、CH376S 裸芯片、5V 负载开关、ESD。
- AUX 输入单元：插座、防静电、偏置、滤波、Codec/ADC 接入。
- 音频处理单元：I2S 数字音频、左右声道选择、音量控制、静音。
- 功放单元：MAX98357A x2、5V 功放电源、增益/声道配置、输出保护、喇叭接口。
- 电源单元：USB-C 5V 输入、IP5306、1S 3.7V 2500mAh 锂电池、保护、边充边播验证、升压 5V、SY8088IAAC 3.3V Buck、模拟/数字/功率电源分区。
- 控制单元：MCU、按键/旋钮、LED、输入检测、静音控制。

## 3. 蓝牙音频方案

推荐路线：

- 使用 ESP32-WROOM-32E 模块，不使用蓝牙音频成品模块。
- 基于 ESP-IDF 的 Classic Bluetooth A2DP sink API 接收手机/电脑蓝牙音频。
- 通过 ESP32 I2S 输出数字 PCM，直接进入 MAX98357A x2 数字功放，左右声道各 1 颗。
- 淘宝上常见的杰理 AC69xx、中科蓝讯 AB53xx 等蓝牙音频芯片便宜，但资料和 SDK 往往封闭，更像套成熟方案；本项目为了简历展示，优先选择 ESP32 这种资料公开、代码可解释、调试过程可展示的方案。

设计内容：

- ESP32 3.3V 供电滤波。
- EN 复位、GPIO0 下载、UART 下载/日志电路。
- 复位和启动配置。
- UART 下载和日志接口。
- ESP32-WROOM-32E 模块天线区按官方 datasheet 留净空，不在天线区域铺铜、走线或放金属件。
- I2S 数字音频输出。
- ESP32 可以输出 PCM/I2S 数字音频流；首版直接用 MAX98357A 接收 I2S 并完成 D/A 转换和功率放大，不使用 ESP32 内部 DAC 作为正式音频输出。

重点风险：

- 模块天线净空不足会导致连接距离差。
- 模块下方和天线前方铺铜、走线、靠近金属外壳或喇叭磁钢会影响蓝牙稳定性。
- A2DP、TF/SD、本地解码、U 盘读取和 AUX 输入切换会带来较高固件复杂度。

建议：

- 在画原理图前，必须下载并归档 ESP32 datasheet、硬件设计指南和 ESP-IDF A2DP/I2S 示例。
- 第一版严格参考 ESP32-WROOM-32E datasheet 的模块摆放和天线 keepout 要求。

## 4. 电脑连接方案

首版结论：

- USB-C 只用于 5V 供电和给 1S 锂电池充电，不走 USB 数据。
- USB-A 只用于 U 盘 Host，不再兼做电脑声卡。
- 电脑近场听音优先使用蓝牙 A2DP。
- 电脑有线输入通过 3.5mm AUX 实现，AUX 需要经过 Codec/ADC 转入 ESP32/I2S 音频链路。

这样做的原因：

- ESP32-WROOM-32E 不提供可直接做 USB Audio Device 的原生 USB 接口；做 USB 声卡必须额外增加 USB Audio 控制器或带 USB Audio 的 MCU。
- 你已经确定 USB-A 只接 U 盘，继续加入 USB 声卡会引入 USB Host/Device 角色切换、电源方向和数据切换问题。
- 取消 USB Audio 可以减少芯片数量、BOM 成本、PCB 风险和固件调试量，更适合九月前完成可展示样机。

## 5. 本地播放方案

首版新增 TF/SD 卡和 U 盘播放，建议把目标收敛为“能稳定播放 MP3/WAV”，不要一开始追求所有无损格式。

推荐架构：

```text
TF/SD 卡 -> ESP32 SPI -> FAT 文件系统 -> MP3/WAV 解码 -> I2S -> MAX98357A x2
U 盘 -> CH376S -> ESP32 SPI -> MP3/WAV 解码 -> I2S -> MAX98357A x2
```

推荐芯片策略：

- ESP32 负责蓝牙 A2DP、本地播放状态机、MP3/WAV 解码、按键/LED、音源切换和 I2S 输出。
- TF/SD 卡由 ESP32 通过 SPI 读取；首版 TF/SD 和 U 盘两个都做。
- U 盘不建议首版让主控直接写 USB Host 栈；首版固定使用 CH376S 裸芯片，通过 SPI 让 ESP32 读取文件，速度和工程展示性都更好。CH376 只作为同系列备选，不在首版文档中继续混用。

格式边界：

- 首版支持：MP3、WAV。
- 后续再评估：FLAC、AAC、APE、播放列表、断点续播。

注意：

- U 盘接口需要独立 5V 电源开关和过流保护。
- U 盘 D+/D- 只连接 USB Host/文件管理芯片，不与 USB-C 或其他 USB 数据链路相连。
- TF/SD 卡和 U 盘都需要软件处理插拔异常；首版 TF/SD CD 和 CH376S INT 不接 ESP32，只预留测试点，固件通过挂载/轮询处理。
- 本地播放通过播放/暂停键和音源切换键操作；旋转编码器只负责音量。
- 文件系统首版优先 FAT32。

## 6. 音频链路方案

推荐数字链路：

```text
蓝牙 I2S ----\
本地播放 I2S -\
               > I2S 音频混合/切换/数字音量 -> MAX98357A x2 -> 左右喇叭
```

有线 AUX 输入链路：

```text
AUX L/R -> ES8388 Codec/ADC -> ESP32/I2S 音频链路 -> MAX98357A x2
```

首版建议：

- 主喇叭输出已经固定为 MAX98357A x2 数字功放，因此蓝牙、TF/SD 和 U 盘优先走 I2S 数字链路。
- AUX 首版要能播放，因此使用 ES8388 把 AUX 转成 ESP32 可处理的数字音频，再输出到 MAX98357A x2。

模拟链路关键点：

- AUX 输入端加 AC 耦合电容。
- 加适当偏置和低通滤波。
- 首版只有一个 AUX 模拟输入，不加模拟开关；蓝牙、TF/SD、U 盘、AUX 的音源切换在 ESP32 固件中完成。
- I2S 线远离 Buck 开关节点和 MAX98357A 喇叭输出。

数字链路关键点：

- I2S 主从关系明确。
- 采样率和位宽统一。
- MCLK/BCLK/LRCLK 走线短且参考地完整。
- 需要处理不同输入源的时钟切换。

## 7. 音量控制方案

首版方案：

- 使用旋转编码器调节 ESP32 数字音量。
- 旋转编码器首版只使用 A/B 两相调节音量，不使用按压功能。
- 音量变化同步刷新 0.96 英寸 I2C OLED。

推荐：

- 第一版采用旋转编码器 + ESP32 数字音量。
- 音量曲线使用非线性步进，低音量区域步进更细，高音量区域步进更快。

注意：

- 编码器需要软件消抖，避免音量跳变。
- 数字音量需要设置最小/最大限幅，避免最小音量仍过大或最大音量削波。
- 数字音量需要设置最小/最大限幅，避免最小音量仍过大或最大音量削波。

## 8. 功放方案

推荐：

- 使用 MAX98357A x2 自画双声道 I2S 数字功放电路，左右声道各 1 颗。
- MAX98357A 直接接 ESP32 输出的 I2S/PCM，不再需要独立模拟 DAC 和传统模拟输入功放。
- MAX98357A 使用 5V 功放电源；外部 USB-C 5V 可直接进入 5V 系统电源，1S 电池供电时需要升压到 5V。
- 4 欧姆 5W 喇叭可以继续使用，但首版按近场小功率输出设计，不把 MAX98357A 宣传为满额 2 x 5W。
- 使用 SD/MODE/GAIN 等引脚完成左右声道、增益和静音配置。

设计内容：

- I2S BCLK/LRCLK/DIN 输入和左右声道配置。
- SD/MUTE 控制。
- MAX98357A 5V 电源大电容和去耦。
- I2S BCLK/LRCLK/DIN 走线和串联阻尼预留。
- 左右声道选择和增益设置。
- 输出磁珠或 LC 滤波，按芯片推荐设计。
- 喇叭接口和走线加宽。
- 功放地和电源回路紧凑。

禁止：

- 不要让 MAX98357A 喇叭输出线穿过 I2S、RF 或电源敏感区域。

## 9. 电源方案

首版推荐：

- USB-C 5V 输入用于系统供电、调试和通过 IP5306 给 1S 锂电池充电；锂电池用于便携供电。
- 电池选 1S 3.7V 2500mAh 锂电池，自带保护板，满电 4.2V；保护板负责过充、过放、过流和短路保护。
- 输入端：USB-C 5V 输入，需要 ESD、过流保护、TVS、滤波和输入电压检测；不再需要 USB-C PD 协商/诱骗。
- 充电端：使用 IP5306 做 1S 锂电池充电管理，充满电压 4.2V；2500mAh 电池首版建议充电电流 0.5A-1A，避免边充边播时发热过大。
- IP5306 应用边界：IP5306 支持 1S 充电、5V 升压和充放电同步应用，用在本项目的 5V USB-C + 1S 锂电池路线是合理的；但首版必须按所采购 datasheet 典型应用画原理图，并实测边充边播时的 5V 跌落、温升和充电状态。
- 边充边播注意：系统 5V 负载接 IP5306 输出侧，不能把系统负载直接并到电池充电端。若首版实测出现重启、充电异常或温升过高，第二版再增加外部负载共享、理想二极管或更强电源管理方案。
- 功放：MAX98357A x2 使用 5V 功放电源；USB-C 供电和电池供电都统一从系统 5V 取电。
- 数字电源：系统 5V -> SY8088IAAC -> 3.3V_D，给 ESP32、Flash、OLED、TF/SD 和逻辑电路。
- 模拟电源：ES8388 的模拟电源优先由 3.3V_D 经磁珠/RC 滤波或低噪声 LDO 得到 3.3V_A，具体按 ES8388 datasheet 和首版噪声测试决定。
- 功率边界：IP5306 可以支撑小型便携音箱的 5V 系统，但 MAX98357A x2、U 盘、OLED、ESP32 峰值电流会叠加；首版必须限制最大音量，并实测 5V 跌落、纹波和芯片温升，不按满额 2 x 5W 连续输出设计。

电源树示例：

```text
USB-C 5V 输入 -> IP5306 VIN
1S 锂电池(自带保护板，RH2.0 2P) <-> IP5306 BAT
IP5306 VOUT / 系统 5V -------------------+--> MAX98357A x2
                                         +--> USB-A 负载开关 -> U盘 5V
                                         +--> SY8088IAAC -> 3.3V_D -> ESP32、Flash、OLED、TF/SD、逻辑
                                         +--> 滤波/LDO -> 3.3V_A -> ES8388 模拟电源
```

注意：

- 开关电源远离蓝牙天线和模拟音频。
- 模拟 LDO 输出要低噪声。
- 每个芯片电源脚附近放置去耦电容。
- 预留电流测试点。
- 1S 锂电池自带保护板仍要核对保护参数，PCB 上仍需清楚标注正负极并做好防短路设计。
- 电池接口使用 RH2.0 2P，需要在 PCB 丝印上标清正负极；电池仓需要固定、绝缘、防反接和防挤压设计。
- IP5306 的 SW、BAT、VOUT、VIN、电感和电容连接必须按所采购芯片 datasheet 的典型应用图画，不按口头简化电源树自行改接。

## 10. MCU 控制方案

MCU 负责：

- 输入选择。
- 旋转编码器读取、消抖、加速和数字音量映射。
- TF/SD 卡文件扫描和播放控制。
- U 盘文件扫描和播放控制。
- 读取旋转编码器 A/B、播放/暂停键和音源切换键；IP5306 开关机由独立电源按键负责。
- 控制 LED 状态。
- 控制 0.96 英寸 I2C OLED 显示音源、音量、电量、播放状态和蓝牙连接状态。
- 控制 MAX98357A 静音/使能。
- 控制 Codec/ADC、蓝牙状态和 U 盘文件管理芯片。
- 首版不使用 I2C GPIO 扩展器；只保留编码器 A/B、播放/暂停键和音源切换键，直接接 ESP32。

首版固件状态：

- 上电初始化。
- 默认蓝牙、TF/SD、U 盘或 AUX 中的一个输入。
- 按键切换输入。
- 本地播放模式下支持播放/暂停和音源切换；首版不做上一曲/下一曲独立控制。
- 音量改变后更新 ESP32 数字音量和 OLED 音量显示。

## 11. PCB 设计重点

- 蓝牙天线区域必须留净空。
- USB 差分线按阻抗走线，少过孔。
- USB-C 只走 5V 供电/充电，不走 USB 数据；USB-A 是 U 盘 Host 口，D+/D- 只连接 USB Host/文件管理芯片。
- U 盘 5V 供电需要电源开关和过流保护。
- TF/SD 卡座靠近板边，保留插拔空间和 ESD。
- 模拟音频线短、成对、远离高频开关节点。
- D 类功放输出和 Buck 电感节点远离前级。
- 功率地、数字地、模拟地合理规划。
- 功放电源回路要短而粗。
- 所有关键信号加测试点。
- OLED 使用 I2C，SCL/SDA 走线短一些，预留上拉电阻，避免和 I2S/RF 走线贴太近。
- 用户指定首版使用 2 层板；第一版 PCB 宁可稍大，也要方便测量和返修。
- 2 层板必须尽量保持底层 GND 连续，RF、ES8388 AUX 输入、MAX98357A 喇叭输出和 IP5306/SY8088 开关节点分区布线。

## 12. 推荐首版规格

- 场景：电脑桌近场听音。
- 声道：2.0 立体声。
- 喇叭：2 只 4 欧姆 5W 全频喇叭；首版按近场小功率使用。
- 蓝牙/主控：ESP32-WROOM-32E 模块。
- 主控：ESP32-WROOM-32E 负责蓝牙、本地播放、按键/LED、音源切换和系统状态机；额外 MCU 只作为后续扩展，不放入首版核心方案。
- 电脑输入：首版走蓝牙；有线电脑输入通过 AUX + Codec/ADC 播放，暂不做 USB Audio。
- 本地播放：TF/SD 卡 + U 盘，首版支持 MP3/WAV。
- U 盘接口：一个 USB-A Host 口 + CH376S 裸芯片，和 ESP32 走 SPI。
- AUX：3.5mm 模拟输入，通过 ES8388 Codec/ADC 接入 ESP32/I2S 链路。
- 音量：旋转编码器 + ESP32 数字音量。
- 显示：0.96 英寸 I2C OLED，推荐 SSD1306 128x64。
- 功放：MAX98357A x2 I2S 数字功放，左右声道各 1 颗。
- PSRAM：首版不加。
- 控制：ESP32 负责状态机；OLED 和 ES8388 共用 I2C；编码器和两个功能按键直接接 ESP32。
- 供电：USB-C 5V 输入 + IP5306 + 1S 3.7V 2500mAh 锂电池，自研 1S 充电、保护、边充边播验证、升压 5V 和 SY8088IAAC 3.3V 降压电路。
