# ESP32 引脚分配表

更新日期：2026-07-09

## 1. 当前结论

- 主控：ESP32-WROOM-32E 模块。
- 外部 Flash：首版不单独购买，使用 WROOM-32E 模块内置 Flash。
- PSRAM：首版不加。
- TF/SD：SPI。
- U 盘：CH376S 裸芯片，SPI 接 ESP32。
- AUX：ES8388 做 Codec/ADC。
- 喇叭功放：MAX98357A x2。
- USB-C：只供电/充电。
- USB-A：只接 U 盘。
- IP5306：KEY 用实体按键直接控制，ESP32 不负责 IP5306 开关机逻辑。
- PCB：用户指定首版 2 层板；该方案按 2 层板可调试优先分配，但 RF、音频和电源风险高于 4 层板。

## 2. I2S 架构推荐

推荐使用两个 I2S 外设：

- I2S0：ESP32 -> MAX98357A x2，负责喇叭播放。
- I2S1：ES8388 -> ESP32，负责 AUX 采集。

原因：

- 蓝牙/TF/U 盘播放是输出流，AUX 是输入流，分开后 bring-up 更清楚。
- MAX98357A 和 ES8388 的时钟、数据方向不同，分开可以减少首版调试变量。
- 后续可分别验证：先让 I2S0 播放测试音，再让 I2S1 采集 AUX。
- 缺点是多占 GPIO。用户已决定精简 UI，不使用 I2C GPIO 扩展器，因此 UI 会占用少量启动绑带脚，原理图必须控制默认电平。

不推荐首版把 ES8388 输入和 MAX98357A 输出硬塞到同一个 I2S 外设。虽然 ESP32 可以做复杂的 I2S 路由，但首版会增加时钟同步、全双工配置和软件调试难度。

## 3. 为什么 WROOM-32E 不再画外部 Flash/晶振/RF

ESP32-WROOM-32E 模块内部已经集成 ESP32 芯片、SPI Flash、40MHz 晶振、射频匹配和 PCB 天线。首版使用模块后，原理图不再单独画外部 Flash、晶振和 RF 匹配网络。

这样做的原因：

- 降低首版 RF、Flash、晶振和 QFN 焊接风险。
- 更容易在九月前做出可演示样机。
- 仍然可以展示 I2S、ES8388、MAX98357A、电源、U 盘、TF/SD、PCB 和固件状态机能力。
- V2 可以再迁移到 ESP32-D0WD-V3 裸芯片方案，作为进阶版本。

结论：首版不使用 GPIO6-GPIO11，也不画外部 Flash 总线；TF/SD 和 CH376S 另走 VSPI。

## 4. ES8388 DAC 替代双 MAX98357A 的取舍

ES8388 的 DAC 输出是模拟小信号，不能直接驱动 4 欧姆 5W 喇叭。如果用 ES8388 DAC 代替双 MAX98357A，还需要再加模拟功放或模拟输入 D 类功放。

可能好处：

- 可得到模拟音频输出，后续做耳机、Line out 或模拟功放更自然。
- ES8388 可统一处理 AUX ADC 和 DAC，音频链路更像传统 Codec 架构。
- 如果后续改用模拟功放，输入接口会更直接。

不推荐首版这样做的原因：

- 仍然需要额外功放，ES8388 自己推不动 4 欧姆 5W 喇叭。
- 模拟小信号到功放之间更容易引入底噪、电流声和串音。
- 2 层板上模拟音频线、D 类功放输出和电源开关节点更难隔离。
- 当前双 MAX98357A 方案是 I2S 直接进数字功放，链路短，调试目标清楚。

结论：首版 ES8388 只做 AUX Codec/ADC；喇叭继续用双 MAX98357A。

## 5. 2 层板约束

用户指定首版用 2 层板。可以做，但必须按“可调试、可返修、尺寸稍大”的思路设计。

硬性约束：

- 底层尽量保持连续 GND，不要被长电源线和信号线切碎。
- ESP32-WROOM-32E 模块天线区严格净空，按模块 datasheet 放在板边。
- MAX98357A 喇叭输出远离 ESP32 RF、ES8388 AUX 输入和 I2S 线。
- IP5306、SY8088、功放电源回路要短而粗。
- ES8388 模拟输入区单独布局，远离电感、USB-A、喇叭线。
- U 盘 USB D+/D- 短、等长、少过孔。
- 第一版多放测试点，不追求小板。

风险：

- 蓝牙距离可能比 4 层板差。
- ES8388 AUX 底噪更容易受电源和功放影响。
- D 类功放和 Buck/Boost EMI 更难压。
- 返板概率高于 4 层板。

## 6. ESP32 专用/禁用引脚

| GPIO | 首版处理 | 原因 |
|---|---|---|
| GPIO6-GPIO11 | 不使用 | WROOM-32E 模块内部 Flash 占用/不作为外设 GPIO 使用 |
| GPIO0 | 只做 BOOT/下载相关，不接普通外设 | 启动绑带脚 |
| GPIO1/GPIO3 | UART0 下载/日志 | 调试必需 |
| GPIO12 | 避免使用 | 启动绑带脚，可能影响 Flash 电压配置 |
| GPIO2/GPIO4/GPIO5/GPIO15 | 尽量少用；若使用必须核对上拉/下拉 | 启动绑带相关；首版只把 GPIO5/GPIO15 用作 SPI 片选，不接人工按键 |
| GPIO34-GPIO39 | 仅输入 | 不能输出，适合 ADC、INT、插卡检测 |

## 7. 推荐 GPIO 分配

### UART 下载与调试

| 功能 | ESP32 引脚 | 说明 |
|---|---:|---|
| UART0 TXD | GPIO1 | 下载/日志 |
| UART0 RXD | GPIO3 | 下载/日志 |
| EN | EN | 复位电路 |
| BOOT | GPIO0 | 下载按键，按官方参考设计 |

### I2C 总线

| 功能 | ESP32 引脚 | 外设 |
|---|---:|---|
| I2C SDA | GPIO21 | OLED、ES8388 控制 |
| I2C SCL | GPIO22 | OLED、ES8388 控制 |

首版不加 I2C GPIO 扩展器。I2C 只接 OLED 和 ES8388，预留测试点即可。

### I2S0：喇叭输出到 MAX98357A x2

| 功能 | ESP32 引脚 | 说明 |
|---|---:|---|
| I2S0 BCLK | GPIO26 | 输出到两个 MAX98357A |
| I2S0 LRCLK | GPIO25 | 输出到两个 MAX98357A |
| I2S0 DOUT | GPIO27 | 输出到两个 MAX98357A |
| AMP_SD/MUTE | GPIO16 | 控制 MAX98357A 使能/静音 |

两个 MAX98357A 共用 BCLK、LRCLK、DIN，通过芯片 L/R 配置区分左右声道。

### I2S1：AUX 输入从 ES8388 到 ESP32

| 功能 | ESP32 引脚 | 说明 |
|---|---:|---|
| ES8388 MCLK | GPIO33 | ESP32 输出主时钟给 ES8388 |
| I2S1 BCLK | GPIO32 | ESP32 输出位时钟 |
| I2S1 LRCLK | GPIO17 | ESP32 输出左右声道时钟 |
| I2S1 DIN | GPIO35 | ES8388 ADC 数据输入到 ESP32，仅输入脚合适 |

ES8388 作为 I2S slave，ESP32 作为 I2S master。

### VSPI：TF/SD + CH376S 共用 SPI

| 功能 | ESP32 引脚 | 说明 |
|---|---:|---|
| VSPI SCLK | GPIO18 | TF/SD 和 CH376S 共用 |
| VSPI MISO | GPIO19 | TF/SD 和 CH376S 共用 |
| VSPI MOSI | GPIO23 | TF/SD 和 CH376S 共用 |
| TF/SD CS | GPIO5 | TF/SD 片选，启动绑带相关，默认必须为高电平/非选中 |
| CH376S CS | GPIO15 | CH376S 片选，启动绑带相关，默认必须为高电平/非选中 |
| CH376S INT | 不接，预留测试点 | 首版通过 SPI 轮询 CH376S 状态 |
| TF/SD CD | 不接，预留测试点 | 首版通过软件挂载/轮询处理插卡 |

TF/SD 和 CH376S 共用 SCLK/MOSI/MISO，各自独立 CS。固件访问时同一时间只选中一个设备。

### 电源与检测

| 功能 | ESP32 引脚 | 说明 |
|---|---:|---|
| BAT_ADC | GPIO36 | 电池分压检测，只输入 |
| USB_A_PWR_EN | 不接 ESP32，负载开关默认随系统 5V 使能 | 首版减少 GPIO 占用；保留焊盘供第二版改 MCU 控制 |
| USB_A_OC | 不接 ESP32，预留测试点 | 首版不过流中断，调试时用测试点观察 |

USB-A 仍然要使用带限流/过流保护的负载开关，只是首版不把 EN/OC 接入 ESP32。

### IP5306

| 功能 | 连接方式 | 说明 |
|---|---|---|
| KEY | 实体按键 -> IP5306 KEY | 用户已确认用按键控制 |
| LED/状态脚 | 预留测试点 | 首版不和 ESP32 做复杂联动 |
| 电池电量 | ESP32 ADC 读取电池分压 | OLED 显示估算电量 |

## 8. UI 控件分配

用户确认精简 UI：

- 一个旋转编码器 A/B，只用于音量。
- 独立音源切换键。
- 独立播放/暂停键。
- 首版不做上一首/下一首控制。

| 功能 | ESP32 引脚 | 说明 |
|---|---:|---|
| 旋转编码器 A | GPIO34 | 输入专用脚，外接上拉 |
| 旋转编码器 B | GPIO39 | 输入专用脚，外接上拉 |
| 播放/暂停 | GPIO13 | 非启动绑带脚，按下接地，外接上拉 |
| 音源切换 | GPIO14 | 非启动绑带脚，按下接地，外接上拉 |
| GPIO4 | 不接，预留测试点 | 释放启动绑带脚，降低启动风险 |

注意：

- GPIO34/GPIO39 没有内部上拉/下拉，编码器 A/B 必须外接上拉电阻。
- GPIO5/GPIO15 是启动绑带相关脚，只作为 SPI CS，不接人工按键；CS 默认上拉为非选中状态，并按 ESP32 启动要求核对默认电平。
- 播放/暂停和音源切换使用 GPIO13/GPIO14，建议“按下接地 + 外部上拉”。
- 如果首版出现启动异常，第二版优先恢复 I2C GPIO 扩展器方案。

## 9. 仍需原理图前确认

1. ES8388 封装、供电和 line-in 推荐电路。
2. CH376S 裸芯片封装和供电电压。
3. U 盘 5V 负载开关型号。
4. ESP32-WROOM-32E 模块天线 keepout、板边位置和外壳/喇叭避让。
5. GPIO5/GPIO15 作为 TF/SD 和 CH376S 片选时的启动默认电平，需要画原理图时按 ESP32 硬件设计指南逐一核对。
