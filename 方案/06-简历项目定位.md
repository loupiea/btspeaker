# 简历项目定位

更新日期：2026-07-09

## 1. 项目目标

这个项目不是为了最快做出一个能响的音箱，而是为了在 2026 年 9 月求职前形成一个能写进简历、能展示过程、能经得起面试追问的嵌入式/硬件项目。

项目定位：

- 自研 2.0 立体声蓝牙音箱。
- 使用芯片级设计，不使用蓝牙音频成品模块。
- 支持蓝牙、TF/SD、本地 U 盘、AUX 多音源；首版取消 USB Audio，降低硬件和固件风险。
- 自研 USB-C 5V 输入 + IP5306 + 1S 3.7V 2500mAh 自带保护板锂电池供电、充电/升压、边充边播验证、电池保护、电源树、功放、AUX Codec/ADC、音频切换和主控固件。
- 输出完整工程资料：需求、选型、原理图、PCB、固件、调试记录、测试报告、问题复盘。

## 2. 推荐芯片路线

推荐主控/蓝牙使用 ESP32-D0WD-V3 裸芯片，外接 16MB SPI Flash 和 40MHz 晶振。

原因：

- 淘宝容易买，价格低。
- 官方资料、ESP-IDF、A2DP、I2S、SD/SPI 示例都能公开获得。
- 能展示自己写代码、调状态机、调 I2S、调音频链路，而不是套封闭蓝牙音频方案。
- 面试时能讲清楚蓝牙 A2DP、I2S、双 MAX98357A 数字功放、电源、PCB RF Layout 的取舍。

不优先推荐杰理 AC69xx、中科蓝讯 AB53xx 作为首版主控：

- 便宜，但资料和 SDK 通常更封闭。
- 容易变成“拿厂商方案改一改”，面试时不好证明代码和架构能力。
- 适合后续做低成本产品化对比，不适合作为第一版简历项目核心。

## 3. 简历可写亮点

- 设计基于 ESP32 裸芯片的蓝牙 A2DP 立体声音频接收链路，通过 I2S 输出数字 PCM 至双 MAX98357A，实现 2.0 立体声数字功放驱动。
- 实现多音源状态机：Bluetooth / TF card / USB disk / AUX。
- 设计 USB-C 5V + IP5306 + 1S 3.7V 2500mAh 自带保护板锂电池电源系统：1S 充电管理、保护、边充边播验证、升压 5V、数字电源、模拟音频电源分区。
- 设计 MAX98357A x2 I2S 数字功放和 ES8388 AUX Codec/ADC 输入链路。
- 设计旋转编码器、功能按键和 OLED 状态显示交互，完成音源、音量、电量和播放状态的人机界面。
- 完成 2 层 PCB 挑战版设计，处理 RF 天线净空、U 盘 USB 差分线、I2S 数字音频、模拟音频和功放大电流回路。
- 建立硬件 bring-up 流程：限流上电、电源轨测试、U 盘枚举、蓝牙连接、I2S 波形、功放假负载、整机老化。

## 4. 面试讲法

建议按这个顺序讲：

1. 为什么不用现成蓝牙模块：为了展示芯片级设计、固件和调试能力。
2. 为什么选 ESP32：便宜、淘宝易买、官方 A2DP/I2S 支持、资料公开。
3. 系统架构：蓝牙/本地播放/AUX -> 音频切换/数字音量 -> MAX98357A x2。
4. 最大难点：多音源状态机、I2S 音频稳定性、RF Layout、电源噪声、功放 EMI。
5. 如何验证：分块上电、测试点、示波器看 I2S/电源纹波/功放输出、长时间播放测试。
