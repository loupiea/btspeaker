# 蓝牙音箱项目总览

更新日期：2026-07-09

## 1. 项目目标

制作一台面向简历展示的全自研桌面蓝牙音箱，不采用现成蓝牙音频模块、USB 声卡模块、功放模块或电源模块拼装。允许采购芯片、电阻电容、电感、连接器、喇叭、电源适配器、外壳材料等基础器件，但整机电路、PCB、固件、结构和测试流程都由本项目自行设计。

首版必须满足：

- 可连接电脑播放声音。
- 可通过蓝牙连接手机、平板、电脑播放声音。
- 可插 TF/SD 卡播放本地音频文件。
- 可插 U 盘播放本地音频文件。
- 可使用锂电池供电，支持边充边播、充电、保护和电量检测。
- 可调节声音大小。
- 可驱动内置喇叭播放。
- 具备稳定供电、保护电路、可维护结构和测试方法。

## 2. 产品定位

第一版定位固定为“USB-C 5V 输入、1S 3.7V 2500mAh 锂电池供电、支持边充边播的电脑桌近场立体声蓝牙音箱工程样机”：

- 使用场景：电脑桌近场听音，兼顾工作台和卧室小空间。
- 声道：2.0 立体声。
- 功率：首版使用 MAX98357A x2 驱动 2 只 4 欧姆 5W 喇叭；实际输出按近场桌面小功率定位，不宣传满额 2 x 5W。
- 供电：USB-C 5V 输入 + IP5306 + 1S 3.7V 2500mAh 锂电池；外部 5V 供电时给系统供电并给电池充电，电池供电时由 IP5306 升压输出 5V，支持边充边播。
- USB 接口：USB-C 口只用于 5V 供电和给 1S 锂电池充电；USB-A 口只用于 U 盘 Host，不再兼做电脑声卡。
- 电脑连接：首版电脑近场听音优先走蓝牙；有线电脑输入通过 AUX 实现，不做 USB Audio 声卡口。AUX 需要通过 Codec/ADC 接入 ESP32/I2S 数字功放链路。
- 本地播放：TF/SD 卡和 U 盘两个都做，首版优先支持 MP3/WAV；U 盘 Host 芯片固定用 CH376S 裸芯片，和 ESP32 走 SPI。
- 蓝牙连接：首版使用 ESP32-WROOM-32E 模块，不使用蓝牙音频成品模块；基于 ESP-IDF A2DP API 自行实现蓝牙音频接收、I2S 输出、音源切换和状态管理。V2 再评估迁移到 ESP32-D0WD-V3 裸芯片 + 外部 Flash + 晶振/RF 方案。
- PSRAM：首版不加 PSRAM；如果后续做 FLAC、大缓存或复杂 UI，再评估外部 PSRAM。

第一版不追求量产外观，重点是把自研电路链路跑通并可重复制作。

## 3. 首版功能边界

必须做：

- 蓝牙 A2DP 音频输入。
- 电脑可通过蓝牙连接；有线电脑输入通过 AUX 播放。
- TF/SD 卡播放 MP3/WAV。
- U 盘播放 MP3/WAV。
- 输入选择。
- 音量控制。
- 一个旋转编码器只用于调节数字音量；独立按键只保留播放/暂停和音源切换；IP5306 开关机使用独立电源按键。
- 0.96 英寸 I2C OLED 小屏显示音源、音量、电量和播放状态。
- MAX98357A x2 I2S 数字功放分别驱动左右两只全频喇叭。
- 电源输入、锂电池充电/保护、降压、滤波、过流和反接保护。
- PCB 原理图、PCB Layout、BOM、测试记录。

暂缓到后续：
- App 控制。
- Wi-Fi 音频。
- 多音箱组网。
- 高阶 DSP 声学校正。
- 商业认证。

## 4. 总体架构

```text
ESP32-WROOM-32E 模块天线区
  |
  v
ESP32 蓝牙 A2DP/I2S -------------------\
                                      > 音频选择/音量/DSP -> MAX98357A x2 -> 左右喇叭
TF/SD 卡 -> 主控/文件系统/解码 --------/
USB-A U 盘 -> CH376S/USB Host -> ESP32 文件系统/解码 ---/
                                      |
AUX 输入 -> 保护/滤波/ES8388 Codec/ADC -/

USB-C 5V -> IP5306 充电/升压5V ---------------\
1S 3.7V 2500mAh 锂电池(RH2.0 2P) -> 保护 -> 蓝牙、U盘Host、音频、MCU、功放
```

## 5. 推荐技术路线

采用“先评估芯片方案，再自画最小系统板，再集成整机 PCB”的路线：

1. 选定关键器件：ESP32-WROOM-32E、ES8388、CH376S、MAX98357A x2 数字功放 IC、电源 IC。
2. 按 datasheet 和参考设计画最小系统原理图。
3. 先做核心音频链路验证 PCB：蓝牙/TF 或 SD/U 盘/AUX -> 音频处理 -> 功放。
4. 验证成功后再做结构集成版 PCB。
5. 后续再优化射频、EMI、底噪、音质和可生产性。

## 6. 阶段性成果

- 第 0 阶段：需求冻结、芯片选型、资料收集。
- 第 1 阶段：原理图设计和仿真/检查。
- 第 2 阶段：第一版 PCB 打样。
- 第 3 阶段：焊接调试，跑通蓝牙、电脑输入、TF/SD、U 盘、AUX、功放、音量。
- 第 4 阶段：声学和结构样机。
- 第 5 阶段：第二版 PCB 修正。
- 第 6 阶段：小批量试制和测试流程固化。

## 7. 成功标准

第一台工程样机完成时应满足：

- 自研 PCB 可以稳定上电，不烧器件。
- 蓝牙可配对并稳定播放。
- 电脑通过蓝牙或 AUX 可稳定播放。
- TF/SD 卡可读取并播放基础音频文件。
- U 盘可读取并播放基础音频文件。
- 音量控制有效，左右声道输出正常。
- 喇叭输出无明显失真、啸叫或强底噪。
- 连续播放 2 小时无异常过热、死机、断连。
- 原理图、PCB、BOM、焊接记录、测试记录完整保存。
