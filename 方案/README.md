# 蓝牙音箱方案目录

本目录保存“全自研搭建”蓝牙音箱项目的长期计划和工程方案。

> 版本说明：本目录记录了包含 CH376S/U 盘功能的早期完整硬件规划，便于保留设计取舍和 PCB 演进过程。当前可编译固件已经将范围收敛为 Bluetooth、TF 和 AUX 三种音源；TF 当前仅播放 16-bit PCM WAV。请以仓库根目录 `README.md` 和 `software/` 源码作为现行功能基线。

当前方案原则：

- 不使用现成蓝牙音频模块、USB 声卡模块、功放模块或电源模块拼装。
- 首版使用 ESP32-WROOM-32E 通用 MCU/蓝牙模块，不使用成品蓝牙音频接收模块；自行设计音频、电源、接口、PCB、固件、结构和测试流程。
- 首版目标是支持 USB-C 5V 输入、IP5306 和 1S 3.7V 2500mAh 锂电池供电的电脑桌近场 2.0 立体声蓝牙音箱，喇叭由 MAX98357A x2 驱动，并支持边充边播。
- 支持蓝牙输入、电脑蓝牙连接、TF/SD 卡播放、U 盘播放、AUX 输入播放、旋转编码器音量调节、0.96 英寸 I2C OLED 状态显示和立体声喇叭播放。
- USB-C 口只负责 5V 输入和电池充电；USB-A 口只负责 U 盘 Host，首版不做 USB Audio 声卡口。
